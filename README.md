# TrainSphere — Corporate Training & Workshops (Light / Dark Theme)

Single-page **TrainSphere** (Corporate Training & Workshops) website featuring persistent Light and Dark theme switching (`localStorage` + `prefers-color-scheme` system fallback), a hero consultation banner, and a 3-card program showcase, ready for GitHub and Vercel.

## Files Included
- `index.html` — Root entry point for GitHub Pages and Vercel
- `trainsphere-theme-toggle.css` — External stylesheet with CSS custom properties for Light and Dark themes
- `trainsphere-theme-toggle.js` — Theme switcher with `localStorage` persistence and OS color-scheme listener
- `vercel.json` — Vercel static hosting configuration
